# Python Programs Collection

Beginner Python programs covering loops, recursion, input handling and data structures.

## Programs
- **Factorial**: computes n! using a loop and recursion
- **Fibonacci**: prints the first n terms and finds the nth term recursively
- **Struct to Dict**: converts a class, dataclass and namedtuple into dictionaries

## How to run
```bash
python factorial/factorial.py
python fibonacci/fibonacci.py
python struct_to_dict/struct_to_dict.py
```
